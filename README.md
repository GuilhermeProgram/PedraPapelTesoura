# Pedra, Papel e Tesoura

Jogo de console em C# (.NET). Você joga contra o computador em uma melhor de 5 rodadas: quem chegar a 3 pontos primeiro vence.

## Como jogar

1. Instale o [.NET SDK](https://dotnet.microsoft.com/download).
2. Clone o repositório e entre na pasta.
3. Rode `dotnet run`.
4. Digite `pedra`, `papel` ou `tesoura` a cada rodada.

## O que eu pratiquei

- Variáveis e tipos (`int`, `string`)
- Laço `while` e condições (`if / else if / else`)
- Sorteio com `Random`
- Leitura de entrada com `Console.ReadLine()`
